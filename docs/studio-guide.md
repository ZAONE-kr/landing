# 사이트 내용 고치기 (Sanity Studio 사용 안내)

사이트의 글과 카드는 Studio(`https://<사이트 주소>/admin`)에서 고칩니다. 코드는 건드리지 않아도 됩니다.

## 어디서 고치나

왼쪽 목록의 **페이지 폴더**(홈, ABOUT, GIVE & USE, IMPACT, ZAONE LAB, 공통)를 열면 그 페이지의 섹션이 하나씩 나옵니다.
섹션을 누르면 편집 창이 열리고, 맨 위 설명에 "사이트의 어디에 나오는 내용인지" 적혀 있습니다.
인사이트·사업소식·사업보고는 목록 위쪽 블로그 항목에서 글을 씁니다.

## 고치는 순서

1. 글을 고칩니다. 고치면 자동으로 저장(Saved)됩니다. **저장만으로는 사이트에 나가지 않습니다.**
2. 오른쪽 아래 **Publish**를 누릅니다. 사이트에는 Publish한 내용만 나갑니다.
3. 게시 후 이 창을 몇 초 열어 두세요. 사이트를 새로고침했을 때 처음 한 번은 이전 내용이 보일 수 있고, 한 번 더 새로고침하면 바뀐 내용이 보입니다. 그래도 그대로면 늦어도 한 시간 안에 바뀝니다.

## 줄바꿈

- 글은 화면 너비에 맞춰 **자동으로** 줄이 나뉩니다. 줄을 맞추려고 Enter를 누르지 마세요.
- 일부 제목(입력칸 설명에 "Enter를 누르세요"라고 적힌 곳)만 Enter로 줄을 바꿀 수 있습니다. 바꾸지 않으면 자동으로 나뉩니다.

## 카드 목록 (이사진, 로고, FAQ, 수치 카드 등)

- 순서: 카드 왼쪽 손잡이를 끌어서 바꿉니다.
- 더하기: 목록 아래 **Add item**.
- 지우기: 카드 오른쪽 **⋯** 메뉴의 **Remove**.
- 새 카드를 더하면 사진을 꼭 올려야 하는 곳이 있습니다(입력칸에 안내가 있습니다). 처음부터 있던 카드는 사진을 비워 두면 지금 사이트의 사진을 그대로 씁니다.
- 카드 수에는 한도가 있습니다(예: 최대 8장). 한도를 넘으면 Publish가 막히고 이유가 표시됩니다.
- 모든 카드를 지우면 그 섹션은 비어 보입니다. 꼭 필요한 만큼은 남겨 주세요.

## 사진 규격

| 대상              | 규격                                                                                                                                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 이사·감사 사진    | 배경이 투명한 PNG, 가로:세로 = 306:420 (예: 612×840px). 사람이 카드 안에서 보일 모습 그대로 배치(머리 위가 위에서 25~30% 지점, 몸은 카드 아래까지). 올린 사진은 카드를 꽉 채워 보여서 따로 자르거나 옮길 수 없습니다. |
| 기관 로고         | 가로:세로 = 206:80 상자 안에 로고를 위아래·좌우 여백을 두고 가운데 놓은 PNG(투명 또는 흰 배경), 예: 412×160px. 올린 로고는 상자 안에 통째로 보입니다.                                                                 |
| 그 밖의 카드 사진 | 올린 뒤 점(hotspot)을 끌어 꼭 보여야 할 곳에 놓으세요. 카드 모양에 맞춰 잘려도 그곳은 남습니다. 활용 경로는 세로로 긴 사진(500:640), 글로벌 네트워크는 가로로 긴 사진(3:1 안팎)이 잘 맞습니다.                        |

사진 설명(alt) 칸이 있는 곳은 사진에 무엇이 보이는지 적어 주세요. 눈이 불편한 방문자에게 읽어 줍니다.

## 지금은 Studio에서 바꿀 수 없는 것

- 섹션의 배치·색·글자 크기·스크롤 효과(레이아웃)
- 헤더 메뉴, 푸터의 바로가기 링크
- 큰 배경 사진(히어로 등)과 브랜드 영상, 사진 배너의 사진
- GIVE·USE 두 면의 구조, ABOUT 원 다이어그램의 원 개수(5개 고정, 글만 수정)
- 홈 검색 결과 제목·설명

이런 변경은 개발자에게 요청해 주세요.
