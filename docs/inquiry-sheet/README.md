# 문의·뉴스레터 기록 시트 붙이기

홈페이지 문의 폼(`/contact`)에 문의가 들어오면 담당자 메일과 함께 구글 시트에도 한 줄씩 쌓입니다.
홈 맨 아래 뉴스레터 구독 칸에 넣은 이메일도 같은 시트의 다른 탭에 쌓입니다(메일은 가지 않습니다).
시트는 단체 구글 계정으로 만들고, 이 폴더의 `Code.gs`를 시트에 붙여 웹 앱으로 배포합니다.

## 처음 한 번

1. **단체 구글 계정**으로 새 Google 스프레드시트를 만듭니다. 이름은 자유입니다(예: `ZAONE 홈페이지 문의`).
   아래쪽 탭 `시트1`은 이름을 `문의`로 바꿔 두면 그 탭에 쌓입니다(그대로 두면 `문의` 탭이 새로 생깁니다).
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**에서 다음을 넣고 저장합니다.
   - 속성: `SECRET`
   - 값: 아무도 모를 긴 글자. 터미널에서 `openssl rand -hex 24`로 만들 수 있습니다.
5. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(⚙): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (홈페이지 서버가 구글 로그인 없이 부르기 때문입니다. 대신
     `SECRET`을 모르면 아무것도 쓸 수 없습니다.)
6. **배포**를 누르고 권한을 승인합니다. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로
   이동**을 누릅니다. 내 시트에 쓰는 권한을 내 계정에 주는 것입니다.
7. 마지막 화면의 **웹 앱 URL**을 복사합니다.
8. 홈페이지 환경 변수에 넣습니다. 로컬 개발은 `.env.local`, 운영은 Vercel 프로젝트의 Environment Variables입니다.

   ```bash
   INQUIRY_SHEET_URL=복사한 웹 앱 URL
   INQUIRY_SHEET_SECRET=4번에 넣은 값
   ```

## 시트 모양

- 네 종류의 문의가 `문의` 탭 하나에 시간순으로 쌓입니다. 종류는 `문의 종류` 열에 있고, 필터로 나눠 볼 수 있습니다.
- 열은 모든 문의에 있는 칸이 앞, 종류마다 다른 칸이 뒤입니다. 해당 없는 칸은 비어 있습니다.

  | 접수 일시 | 문의 종류 | 기업 또는 기관명 | 담당자명 | 이메일 | 연락처 | 소속/부서 | 이용지역 | 관심 있는 협력 분야 | 교육 대상 | 주요 이용 대상 | 자원 설명 | 활용 계획 | 개인정보 수집·이용 동의 |
  | --------- | --------- | ---------------- | -------- | ------ | ------ | --------- | -------- | ------------------- | --------- | -------------- | --------- | --------- | ----------------------- |

- 개발·미리보기 사이트에서 보낸 시험 문의는 `[테스트] 문의` 탭에 따로 쌓입니다. 탭째 지워도 됩니다.
- 첫 줄 이름으로 칸을 찾아 넣으므로, 열을 더하거나(처리 상태, 담당자 메모 등) 순서를 바꿔도 됩니다.
  첫 줄의 이름을 바꾸면 그 칸은 새 열로 다시 생깁니다.
- 뉴스레터 구독 이메일은 `뉴스레터 구독` 탭에 쌓입니다. 탭이 없으면 첫 구독 때 생깁니다.

  | 구독 일시 | 이메일 |
  | --------- | ------ |

  같은 이메일이 이미 탭에 있으면 다시 넣지 않습니다(대소문자는 가리지 않습니다). 구독한 사람에게는 똑같이
  "구독 신청이 완료되었습니다"라고 보입니다. 시험 구독은 `[테스트] 뉴스레터 구독` 탭에 쌓입니다.

## 운영할 때

- 폼의 개인정보 동의문에 "문의 처리 종료일까지 보유하고 처리 목적 달성 시 지체 없이 파기"한다고 안내합니다.
  **처리가 끝난 문의는 시트에서 줄을 지우고, 메일함의 알림 메일도 지워 주세요.** (메일 발송 서비스 Resend는 보낸
  메일을 30일 뒤 스스로 지웁니다. 개인정보 처리방침 4항에 적어 두었습니다.)
- 문의자는 메일이 보내질 때까지만 기다리고, 시트 저장은 그 뒤에 마저 끝납니다. 시트가 잠시 안 되어도 담당자 메일은
  갑니다(메일도 시트도 안 될 때만 문의자에게 다시 시도하라고 안내합니다).
- 뉴스레터는 이 시트가 유일한 기록이라, 시트가 안 되면 구독자에게 다시 시도하라는 알림창이 뜹니다.
- 개인정보 처리방침에 "구독을 해지하면 지체 없이 파기"한다고 안내합니다. 구독 해지 요청을 받으면
  **`뉴스레터 구독` 탭에서 그 줄을 지워 주세요.** 뉴스레터를 보낼 때 메일 끝에 해지 방법(예: 이 메일에 답장)을
  적어 두면 좋습니다.
- 완료·실패 알림창 글은 Studio의 홈 → 뉴스레터에서 고칩니다.

## Code.gs를 고쳤을 때

이 폴더의 `Code.gs`가 바뀌면 Apps Script 편집기의 코드를 모두 지우고 새 `Code.gs`를 붙여 넣은 뒤 저장합니다.
저장만 하면 반영되지 않습니다. **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 누르세요.
이렇게 하면 웹 앱 URL이 그대로라 환경 변수를 바꾸지 않아도 됩니다(새 배포를 만들면 URL이 바뀝니다).
